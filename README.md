# era92 Fund — Investor Dashboard

Interactive dark-mode dashboard for era92 Fund investors, displaying FY 2026 financial performance data from era92 Finance and era92 Ventures.

## Live Dashboard

🔗 **[View Dashboard](https://YOUR_GITHUB_USERNAME.github.io/era92-investor-dashboard/)**

## Features

- **Real-time data** from Google Sheets (auto-refreshes)
- **Dark mode** with era92 brand colors
- **4 tabs**: Overview, era92 Finance, era92 Ventures, Loan Portfolio
- **Interactive charts** powered by Chart.js
- **KPI cards** for key financial metrics
- **Mobile responsive** design
- **Print-friendly** layout

## Setup for Live Google Sheets Data

To enable automatic data updates:

1. Open the spreadsheet in Google Sheets
2. Go to **File → Share → Publish to web**
3. Select the sheets you want to publish
4. Click **Publish**
5. Ensure the spreadsheet is set to "Anyone with the link can view"

The dashboard will automatically fetch the latest data each time it's loaded.

## Deploying to GitHub Pages

1. Create a new GitHub repository named `era92-investor-dashboard`
2. Push this folder to the repository
3. Go to **Settings → Pages**
4. Set source to "Deploy from a branch" → select `main` branch
5. Your dashboard will be live at `https://YOUR_USERNAME.github.io/era92-investor-dashboard/`

## Data Updated

Data is reviewed and updated on the **6th of each month** reflecting the previous month's performance.

## Built With

- Chart.js 4.5 for interactive visualizations
